# VideoFrameCut — FrameCut

Windows용 **프레임 정확도 우선** 영상 분할·선택 추출 프로그램 (설계 단계)

> 상태: 요구사항 검토 및 초기 설계. 실행 가능한 프로그램은 아직 구현되지 않았습니다.

## 개발 목표

LosslessCut처럼 타임라인에서 직접 구간을 나누고, 불필요한 구간을 비파괴적으로 제외하며, 원하는 시간 간격으로 남은 영역을 다시 나눌 수 있는 도구입니다. 선택한 구간은 개별 MP4로 저장하고, **서로 이웃한 출력이 원본 프레임을 중복하거나 건너뛰지 않았는지** 검사합니다.

### 핵심 원칙

1. 편집·출력의 기준은 키프레임이 아닌 **원본의 표시 프레임 순서**입니다.
2. 구간은 `[시작 프레임, 종료 프레임)`으로 표현합니다.
3. CFR과 VFR을 모두 고려하며, VFR에서는 실제 PTS와 프레임 인덱스를 사용합니다.
4. **정확성·안정성 > 무재인코딩**입니다. 필요하면 재인코딩합니다.
5. 원본은 절대 덮어쓰지 않고, 삭제는 편집 목록에서 제외하는 작업입니다.
6. 원본 FPS 보존과 H3용 24fps 변환은 **검증 기준이 다른 두 출력 모드**입니다.

## 첫 번째 목표(MVP)

- 영상 분석: 해상도/코덱/FPS/재생 시간/표시 프레임 인덱스
- 타임라인, 미리보기, 프레임 이동 및 수동 분할
- 구간 선택·다중 선택·제외·Undo/Redo
- 남은 원본 구간을 N초 단위로 자동 분할
- 선택 구간 개별 출력(MP4, NVENC/CPU 대체)
- 출력 로그, 프레임 수/구간 경계 검증, JSON/CSV 매니페스트
