# VideoFrameCut — FrameCut

Windows용 **프레임 정확도 우선** 영상 분할·선택 추출 프로그램입니다.

> 프로젝트 상태: **초기 설계 완료 / 구현 전**. 현재는 설계 문서만 있으며 실행 가능한 프로그램은 없습니다.

## 만드는 이유

LosslessCut처럼 타임라인에서 원하는 위치를 나누고, 반디컷처럼 불필요한 구간은 비파괴적으로 제거한 뒤, **남긴 구간만 지정한 시간 간격으로 다시 분할해 개별 MP4로 추출**하는 도구입니다.

핵심은 빠른 무재인코딩이 아니라 **키프레임 위치에 관계없이 원본의 표시 프레임을 정확히 배분**하는 것입니다.

## 확정한 설계 원칙

1. **원본 프레임 그대로:** 소스의 표시 프레임 순서와 프레임 수를 유지하고 구간마다 중복·누락이 없도록 합니다.
2. **원본 FPS/타이밍 유지:** CFR은 원본 FPS, VFR은 원본 프레임의 실제 시간 간격을 보존합니다. **FrameCut에서 24fps로 미리 변환하지 않습니다.** H3의 영상 입력 처리는 H3에 맡깁니다.
3. **재인코딩 허용:** 프레임 정확도가 더 중요하므로 필요한 경우 전체 구간을 재인코딩합니다. RTX NVENC와 소프트웨어 대체 경로를 설계합니다.
4. **비파괴 편집:** 원본 파일을 수정하지 않습니다. 삭제는 편집 목록에서 제외하는 의미입니다.
5. **선택 출력:** 전체 분할 후 원하는 구간만 체크해 각각 MP4로 출력합니다.
6. **검증:** 편집 범위의 프레임 소유권, 출력별 실제 디코딩 프레임 수, 타임스탬프와 오류를 확인합니다.

## 사용 예시

- 3분 31초 영상을 25초 간격으로 분할 → **25초 목표 구간 8개 + 잔여 구간 1개**, 총 9개 (정확한 컷은 실제 프레임 경계에 맞춤)
- 1~10번 구간 중 **2~7번만 출력**
- 원본 0~10초를 제외하고 **10~60초를 10초 단위**로 분할
- 수동 컷 → 불필요한 구간 삭제 → 남은 구간 자동 분할 → 선택 출력
