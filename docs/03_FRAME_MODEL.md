# 03. 프레임 기반 모델과 편집 알고리즘

## 기준 축

FrameCut의 편집 기준은 **원본 비디오의 디코딩 후 표시되는 프레임 순서**다. 디코딩 순서(DTS), 키프레임, FFmpeg 패킷 인덱스를 표시 순서 프레임과 혼동하지 않는다.

- 원본 표시 프레임: `F[0], F[1], ..., F[N-1]`.
- 편집 구간: `[a,b)` → `F[a] ... F[b-1]`; 길이(프레임) = `b-a`.
- 전체 영상: `[0,N)`.
- 인접 구간: `[a,b)`, `[b,c)` — 프레임 중복 및 누락 0.
- 구간이 `[a,b)`와 `[c,d)`이고 `b < c`이면 사이 `[b,c)`는 삭제/제외됨. 자동 병합 금지.

예: 24fps에서 25초 컷

```text
0번  [0, 600)       원본 표시 프레임 0..599
1번  [600, 1200)    원본 표시 프레임 600..1199
2번  [1200, 1800)   원본 표시 프레임 1200..1799
```

## 시간으로 분할하는 방식

1. 현재 남은 구간 목록에서 대상 구간 `[a,b)`를 하나씩 순회한다.
2. 구간 첫 프레임의 실제 PTS를 시작점으로 삼고, `durationSeconds` 간격의 목표 시간을 만든다.
3. 시간→프레임 검색은 소스 비디오 **표시 프레임별 실제 PTS**를 사용한다.
4. 목표 시각에 가장 가까운 **유효한 프레임 사이 경계** `k`를 선택한다. 동률일 때 규칙(이전/이후 우선)은 테스트에서 고정한다.
5. `a < k < b`일 때만 컷을 생성하고, 같은 경계를 중복 삽입하지 않는다.
6. 마지막 `[last,b)`는 길이가 짧더라도 그대로 유지한다.
7. 삭제된 구간은 대상에 포함하지 않으며 이미 존재한 수동 경계를 넘어서지 않는다.

### CFR과 VFR

- CFR에서는 프레임 번호·timebase로 시간 관계를 설명할 수 있지만, 실제 입력의 프레임 인덱스를 우선 검증.
- VFR에서는 **평균 FPS × 초**로 원본 프레임 번호를 계산하면 안 됨.
- PTS는 유리수 timebase의 정수 기준으로 보관하고, 표시/요청의 초 변환은 별도로 수행.
- 비디오 시간의 시작점이 0이 아닐 수 있음. 출력 파일은 시작 타임스탬프를 0 근처로 정규화하되 **프레임 간 간격은 유지**.
- 중복/누락/역전 PTS, 손상 파일은 자동 보정한 척하지 않고 진단·정책에 따라 거부/경고.
- 종료 경계 `b=N`의 실제 끝 시간은 마지막 프레임 표시 기간 또는 컨테이너 duration과 다를 수 있어 별도 처리.

## 수동 편집

### 수동 나누기

`[a,b)` 내부 `k`에서 분할하면 `[a,k)`, `[k,b)`로 교체. `k=a` 또는 `k=b`는 빈 구간을 만들지 않음.

### 삭제(비파괴)

선택한 세그먼트를 편집 목록에서 제외. 원본 범위와 원본 영상 자체에는 변화 없음. 삭제 전 상태는 Undo 스택에 기록.

### 출력 포함 토글

삭제와 별개: 세그먼트는 타임라인에 남아 있지만 출력하지 않음. UI는 두 상태를 분명히 구별.

### Undo / Redo

- 명령: 분할, 세그먼트 삭제, 범위 조정, 자동 분할, 출력 토글.
- 각 명령의 적용 전/후 세그먼트 구조(고유 ID·순서·범위·출력 여부)를 복원 가능하게 저장.
- 새 편집 명령을 실행하면 Redo 이력 초기화.
- 장시간 인덱싱·인코딩은 편집 명령과 별도의 비동기 작업으로 취급.

## 반드시 통과해야 할 순수 로직 테스트

| 테스트 | 확인 |
| --- | --- |
| 빈/단일 프레임/마지막 프레임 | 유효 범위만 남고 0장 세그먼트 없음 |
| 24fps 25초 분할 | 경계 600, 1200, ... 정확 |
| 211초 25초 분할 | 남은 프레임을 마지막 클립에 포함 |
| VFR 불규칙 PTS | 원하는 시각과 가까운 실제 출력 프레임으로 스냅 |
| 근접한 컷 2회 | 중복 경계 방지 |
| 삭제 범위 중간 존재 | 남은 양쪽을 합치지 않음 |
| 구간 내 자동 분할 | 구간 밖/삭제 구간 변경 없음 |
| 여러 번 Undo/Redo | 전체 범위 및 토글 동일하게 복구 |
| 모호한 PTS | 오류/보류 정책이 명시적이고 결정적 |

## 정확성의 범위

이 모델로 **편집 단계**의 중복/누락을 구조적으로 막는다. 실제 인코더가 그 프레임을 모두 썼는지는 **디코딩 검사**로 별도 확인해야 하며, 디코딩 개수가 맞는 것만으로 프레임 내용까지 일치한다고 단정할 수 없다.
