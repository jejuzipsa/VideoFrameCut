# 04. Windows GUI 기본 설계

테마: Windows 11용 **다크 모드 기본**. 단정한 편집기 형태를 우선하며, 사용자가 자주 누르는 분할/출력/검증을 전면 배치한다.

## 레이아웃 (초안)

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ FrameCut      [영상 열기]                      파일명 / 상태             │
├────────────────────────────────────────────────┬─────────────────────────┤
│                                                │ 원본 정보               │
│               영상 미리보기                    │ 해상도/코덱/FPS         │
│                                                │ 표시 프레임 수/길이      │
│                                                │                         │
├────────────────────────────────────────────────┤ 분할 옵션               │
│ [▶/Ⅱ] [◀1프레임] [1프레임▶] [S 분할]          │ [10.0] 초 [시간으로 나누기]│
│ 현재 00:00:25.000 / Frame 600                  │ 현재 구간/전체 대상     │
├────────────────────────────────────────────────┤                         │

├────────────────────────────────────────────────┴─────────────────────────┤
│ 구간 리스트  □  번호  원본 시작~끝  프레임 범위   길이   상태             │
│             ☑  01    ...           [0,600)       ...    출력            │
```

## GUI 핵심 행동

- 파일을 열면 먼저 미디어 정보를 표시하고 프레임 인덱싱 상태를 보여 줌.
- 헤드 위치를 클릭/드래그로 이동하고 이전/다음 프레임 탐색 가능.
- **S / 나누기**: 재생 헤드가 가리키는 유효 프레임 경계에서 현재 구간 분할.
- 클릭으로 구간 선택, Ctrl/Shift로 다중 선택.
- 우클릭 → 삭제 또는 Delete: 비파괴적으로 편집 목록에서 제외.
- 각 세그먼트의 체크박스는 **출력 포함** 상태. 삭제와 구별해서 표시.
- 자동 분할은 기본적으로 **현재 남은 구간 각각**에 적용. 기존 수동 컷은 보존.
- 분할 결과에 대해 시작·끝 프레임, 시각, 길이, 출력 여부 확인 가능.
- 출력은 체크된 각 구간을 **별도 MP4**로 저장.
- 실패한 구간도 목록과 로그에서 확인할 수 있음.

## 키보드 단축키

| 단축키 | 명령 |
| --- | --- |
| Space | 재생/일시정지 |
| ← / → | 이전/다음 표시 프레임 |
| S | 현재 헤드에서 분할 |
| Delete | 선택 구간 삭제 |
| Ctrl+Z | 실행 취소 |
| Ctrl+Y | 다시 실행 |

## 인코딩 옵션 초안

- 출력 폴더 지정
- 코덱: H.264 (기본 후보)
- 엔진: NVIDIA NVENC 가능 시 기본, 미지원/실패 시 소프트웨어 인코딩 선택
- 품질 프리셋: 고화질 기본, 상세 값은 비교 테스트 후 결정
- FPS: **원본 그대로 (고정 UI 표기)** — 24fps 변환 옵션 없음
- 오디오: 유지 / 제거
- 로그/매니페스트 내보내기

## 상태 표시

1. 입력 분석 중: 프레임 인덱스 처리 상태·취소.
2. 편집 가능: 현재 원본과 남은 구간/선택 출력 수.
3. 내보내기: N개 중 처리 완료 수, 각 구간 진행률/성공/실패.
4. 검증: 출력 프레임 수 확인/불일치/건너뛰기(사유).
5. 오류: 로그 파일 열기 버튼 제공.
