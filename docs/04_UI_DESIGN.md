# 04. Windows GUI — 원본/분할 구간 이중 목록

다크 모드 WPF 편집기입니다. **원본 파일 목록과 해당 원본에서 잘라낸 구간 목록은 서로 별도로 표시합니다.** 2026-11-13에 최초 UI를 구현했습니다.

## 현재 레이아웃

```text
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│ [영상 추가] [원본 전체 보기] [선택 구간 재생] [재생/일시정지] [◀][▶] [정확한 프레임 보기]│
├───────────────────────┬──────────────────────────────────────┬───────────────────────────┤
│ ① 원본 영상 목록      │         영상 미리보기                │ 편집                      │
│                       │                                      │  [25]초 [시간으로 나누기] │
│ 1. source_a.mp4        │   원본/선택한 구간 중 하나 재생        │  구간 첫/마지막 프레임     │
│    1080p · 3000 frames │                                      │  [나누기] [선택 삭제]     │
│ 2. source_b.mkv        │                                      │  [Undo] [Redo]            │
│    4K · 6000 frames    │                                      │ 출력                      │
│                       │                                      │  NVENC/CPU, 오디오        │
│ [창에 파일 끌어 놓기]  │                                      │                           │
│ [목록에서 제거]       │                                      │                           │
├───────────────────────┴──────────────────────────────────────┴───────────────────────────┤
│ 타임라인/재생 헤드 (구간을 선택하면 해당 범위로 제한)                                00:00 │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ ② 분할 구간 목록                                                                       │
│ 출력 | 번호 | 시작 | 끝 | [원본 frameStart, frameEnd) | 프레임 수 | 길이                   │
│ ☑    | 001  | 0초  | 25초 | [0, 750)                 | 750       | 25초                   │
│ ☑    | 002  | 25초 | 50초 | [750, 1500)             | 750       | 25초                   │
│ ☐    | 003  | 50초 | 75초 | [1500, 2250)            | 750       | 25초                   │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ [체크한 구간 MP4 출력]                  상태 / 진행률                      [작업 취소]  │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

## 조작 방법

1. **영상 추가**를 눌러 여러 파일을 선택하거나 창 안으로 `MP4/MKV/MOV/AVI/WEBM/M4V/MTS/TS` 영상 파일을 끌어 넣습니다.
2. 왼쪽 **① 원본 영상 목록**에서 파일을 선택하면 그 영상의 편집 상태와 **② 분할 구간 목록**이 아래에 나타납니다. 원본마다 분할·삭제·Undo/Redo 이력은 메모리 안에서 독립적으로 유지합니다.
3. **수동 분할(S)** 또는 **시간으로 나누기**로 구간을 추가합니다. 삭제는 목록에서만 제외하며 원본 파일을 바꾸지 않습니다.
   **분할 취소(구간 합치기):** Ctrl+클릭이나 Shift+클릭으로 아래 구간 목록에서 연속된 2개 이상 구간의 **행을 선택**한 다음, 오른쪽 **분할 취소 · 구간 합치기** 버튼을 누릅니다. 예를 들어 `[7190,7430)` + `[7430,7670)`은 `[7190,7670)` (480프레임)이 됩니다. 나머지 구간은 유지됩니다. 체크박스는 출력 여부 설정이며 병합 대상을 선택하는 버튼이 아닙니다.
   병합 조건: 선택한 구간들의 원본 프레임 끝/시작이 정확히 연속해야 합니다. 중간에 제외·삭제한 프레임이 있거나 비연속적인 행을 선택하면 병합 버튼은 비활성화됩니다. 병합은 인코딩 없이 원본 편집 구간 모델의 경계를 제거하는 작업입니다. Ctrl+Z로 병합을 취소하고 Ctrl+Y로 다시 적용할 수 있습니다.
   출력 체크 상태가 서로 달랐다면 **합친 구간은 기본적으로 출력 제외**로 설정해, 이전에 제외했던 프레임을 실수로 출력하지 않도록 합니다. 합친 후 원하면 직접 다시 체크하세요.
4. 아래 **구간 하나를 클릭**하면 미리보기/타임라인 범위가 그 구간의 **첫 표시 프레임부터 마지막 표시 프레임까지**로 제한됩니다. 그 상태에서 Space나 재생/일시정지 버튼을 누르면 선택한 구간만 재생합니다.
5. 구간을 **더블클릭**하거나 **선택 구간 재생**을 누르면 구간 첫 프레임으로 돌아가 재생합니다. 재생이 구간의 **exclusive end**에 도달하면 자동 일시정지합니다. 다음 구간으로 연속 재생하지 않습니다.
6. **시작 프레임 확인 / 끝 프레임 확인**은 선택한 구간의 정확한 첫 프레임과 마지막 프레임(`endFrameExclusive - 1`)을 FFmpeg로 디코딩한 정지화면을 보여 줍니다. **원본 전체 보기**는 구간 제한을 해제합니다.
7. 선택한 구간의 체크박스는 출력 여부만 결정합니다. **체크한 구간 MP4 출력**은 현재 선택한 **원본 한 파일의 체크 구간**을 출력합니다.
8. 왼쪽 목록의 **목록에서 제거**는 원본 파일을 삭제하지 않고 앱 목록에서만 제거합니다.

## 다중 원본 병합과 전환 방식 (2026-11-14)

기존 **② 분할 구간 목록** 오른쪽에 **③ 병합 작업** 패널을 추가했습니다. ②에서 선택한 원본 구간들을 원본을 바꿔 가며 ③에 추가하고, 위/아래 버튼으로 순서를 변경합니다. 병합 목록의 항목은 원본과 원본 표시 프레임 범위를 별도로 저장하므로 **원본 A에서 일부 → B에서 일부 → 다시 A에서 일부 → C에서 일부**처럼 재사용할 수 있습니다.

- **기본 (컷 연결):** 이어 붙이기만 수행하며 선택한 영상 경계에 전환이 없습니다.
- **크로스페이드:** FFmpeg xfade transition=fade + acrossfade를 적용합니다.
- **페이드 아웃·인:** FFmpeg xfade transition=fadeblack + acrossfade로 검은 화면을 거칩니다.
- 페이드 전환 시간은 기본 **0.5초**, 0.1~3.0초 사이로 지정합니다. 영상 길이보다 긴 전환은 실행 전에 거부합니다.
- 화면에서 병합 순서를 변경·제거·전체 비우기가 가능합니다. 별도 **병합 → MP4 한 파일 출력** 버튼으로 저장합니다.
- 혼합 해상도/FPS는 **병합 목록의 첫 구간을 기준**으로 영상 크기(레터박스)·FPS(정수 CFR)를 통일합니다. 기존 개별 MP4 출력은 계속 원본 FPS/표시 프레임을 유지합니다.
- 원본 영상은 수정하지 않으며 병합 과정의 임시 세그먼트는 성공·실패·취소 후 정리합니다.

## 영상 아래 재생 컨트롤 (2026-11-13)

영상 미리보기 바로 아래에 일곱 개의 버튼을 추가했습니다.

```text
[⏮ 이전 구간] [« 3초] [‹ 1F] [▶ / Ⅱ] [1F ›] [3초 »] [다음 구간 ⏭]
```

- **이전/다음 구간:** 현재 원본 영상의 보존된 이전/다음 구간으로 이동하여 **해당 구간을 처음부터 재생**합니다. 끝 구간에서는 그 구간을 다시 재생합니다.
- **3초 뒤/앞:** 소스의 표시 프레임 PTS를 기준으로 가장 가까운 유효 표시 프레임으로 이동합니다. **선택한 구간의 첫/마지막 표시 프레임을 넘지 않습니다.**
- **1F 뒤/앞:** 정확한 소스 표시 프레임 정지화면을 FFmpeg로 추출하는 기존 단일 프레임 탐색 기능입니다.
- **▶ / Ⅱ:** 재생 상태에 따라 아이콘이 바뀌며 현재 영상의 재생/일시정지를 전환합니다. 재생 준비가 늦게 끝나는 경우에 기존 재생 명령을 덮어쓰지 않도록 했습니다.
- **슬라이더:** 슬라이더 손잡이를 드래그할 수 있고, 손잡이 밖 **트랙의 아무 곳이나 클릭해 해당 시간/프레임으로 바로 이동**할 수 있습니다 (WPF `IsMoveToPointEnabled`).

## 키보드

| 단축키 | 동작 |
| --- | --- |
| Space | 현재 범위(선택 구간 또는 전체 원본) 재생/일시정지 |
| ← / → | 현재 영상 시간에서 **3초 뒤 / 3초 앞** |
| Ctrl+← / Ctrl+→ (또는 Shift+← / Shift+→) | 현재 범위에서 **1프레임** 뒤 / 앞, 정확한 정지화면 확인 |
| S | 현재 재생 헤드에서 분할 |
| Delete | 선택된 구간 삭제 (원본 목록에 초점이 있을 경우 원본을 목록에서만 제거) |
| Ctrl+Z / Ctrl+Y | 현재 원본 영상 편집 되돌리기/다시 실행 |
| Ctrl+M | 선택한 연속 구간의 분할선 제거(구간 합치기) |

## 정확도에 관한 구분

- **편집 모델/출력:** `[startFrame, endFrame)`이므로 프레임을 구간별로 중복 배분하지 않습니다. 출력은 FFmpeg에서 재디코딩 프레임 수를 검사합니다.
- **구간 재생:** 내장 `LibVLCSharp.WPF VideoView`와 LibVLC 엔진이 원본을 직접 재생하며 약 20ms 간격으로 종료 경계를 확인합니다. VLC 탐색/재생의 시간 오차로 실제 출력과 **미리보기 프레임 경계는 차이가 날 수 있습니다**. 이 재생은 감상용이지 컷 정확도 검증용이 아닙니다.
- **정확한 앞/뒤 프레임:** FFmpeg로 원본 프레임을 직접 뽑는 **시작 프레임 확인 / 끝 프레임 확인** 버튼을 사용합니다. 원본 길이가 길면 디코딩에 시간이 걸립니다.

## 구현되어 있지 않은 사항

- 소스별 편집 내역의 재시작 후 영구 저장.
- 여러 원본을 한 번에 일괄 출력하는 기능. 현재는 원본을 선택한 다음 그 원본의 체크 구간을 출력합니다.
- 반디컷 수준의 비주얼 구간 블록/썸네일 타임라인 및 프레임 정확한 실시간 재생.
- VLC가 지원하지 않는 코덱을 위한 별도 백업 플레이어 (현재 원본 직접 재생을 우선 사용).

## 추가 개발

구간 블록 타임라인, 썸네일·확대, 구간 반복/경계 전후 비교, 프로젝트 저장/불러오기, 일괄 출력, FFmpeg 디코더 기반 고정밀 영상 미리보기 순으로 검토합니다.
