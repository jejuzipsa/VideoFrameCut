# 06. 구현 로드맵 / 작업 단위

2026-11-11 기준: 설계만 등록. 기능·실행파일·테스트는 아직 구현되지 않음.

## 0단계 — 핵심 모델 및 테스트 토대 (가장 우선)

- [ ] .NET 8 솔루션 및 Core/Media/Export/App 프로젝트 구성
- [ ] `FrameRange`, `EditSegment`, `FrameTimeline` 구현
- [ ] 분할/삭제/포함 토글/Undo·Redo 구현
- [ ] 시간 분할 경계 스냅 알고리즘 구현
- [ ] 단위 테스트: CFR 24/30/60, VFR 불규칙 PTS, 빈 구간 방지, 수동 경계·삭제 존중

완료 조건: GUI나 인코더 없이 A~D 시나리오의 예상 **프레임 구간 목록**을 테스트로 확인.

## 1단계 — 실제 원본 프레임 인덱스

- [ ] ffprobe 스트림 정보 및 표시 프레임별 인덱스 수집
- [ ] PTS/timebase/표시 순서 검증 및 비정상 입력 진단
- [ ] 오디오 스트림 유무 탐지
- [ ] 인덱싱 진행률, 취소 및 메모리 사용량 관리

완료 조건: CFR/VFR 샘플에서 프레임 수 및 인덱스 일관성 확인.

## 2단계 — 작은 범위 1개를 정확하게 출력

- [ ] 프레임 범위 기준 디코딩→H.264 인코딩 경로
- [ ] NVENC 감지, 없거나 실패 시 CPU 경로
- [ ] 원본 CFR/VFR 타이밍 유지 정책 확정
- [ ] 원본 오디오 유지/제거 정책
- [ ] 출력 재디코딩 프레임 수·PTS 검증, 실패 로그

완료 조건: 키프레임 경계가 아닌 위치에서도 선택한 프레임 수와 실제 출력 프레임 수가 일치.

## 3단계 — WPF 타임라인 UI 연결

- [ ] 파일 열기·스트림 정보·미리보기
- [ ] 재생 헤드/프레임 이동/수동 컷
- [ ] 다중 선택, 비파괴 삭제, Undo/Redo
- [ ] 시간 자동 분할, 출력 체크박스, 구간 목록
- [ ] 다크 모드 레이아웃 및 키보드 단축키

완료 조건: 사용자가 A~D 시나리오를 화면에서 모두 수행.

## 4단계 — 일괄 출력과 검증·배포

- [ ] 체크 구간만 개별 파일 출력
- [ ] 진행률·취소·개별 실패 처리
- [ ] 출력 폴더·파일명 충돌·매니페스트(JSON/CSV)
- [ ] 장시간/고FPS/VFR/오디오 없음 등 회귀 테스트
- [ ] Windows 포터블 패키징 및 FFmpeg 재배포 라이선스 확인

완료 조건: UI에서 작업 후 파일과 로그/검증 보고서를 재현 가능하게 생성.

## 2차 개선

- [ ] 타임라인 확대·썸네일
- [ ] 컷 경계 앞뒤 프레임 비교
- [ ] 편집 프로젝트 저장/불러오기
- [ ] 다중 영상 일괄 작업
- [ ] H3 Batch GUI에 결과 배치 등록
- [ ] 원본↔출력 프레임 매핑 심화 검증 및 재연결 테스트

## 먼저 해결할 기술 리스크

1. 프레임 인덱싱 시 실제 표시 순서/PTS가 인코딩 입력 순서와 일치하는지.
2. FFmpeg에서 VFR 간격을 재인코딩 후에도 보존할 수 있는지.
3. NVENC 사용 시 출력 색공간/HDR 메타데이터 보존 여부.
4. 타임라인에서 빠른 시킹과 정확한 프레임 단위 미리보기를 어떻게 연결할지.
5. 오디오 시작/끝의 인코더 지연과 컷 경계 정렬.
